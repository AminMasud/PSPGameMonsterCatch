# 60-Veyling roster expansion

The supplied images `031` through `060` are integrated as ten complete,
three-stage families. Their numeric IDs are appended after `001`–`030`, so
existing saves keep every prior species ID unchanged.

| IDs | Family | Element | Wild habitat |
| --- | --- | --- | --- |
| 031–033 | Gillip → Regenol → Axoreign | Tide | Sunthread Marsh |
| 034–036 | Petalimp → Orchidra → Bloomantis | Grove | Fernveil Woods |
| 037–039 | Pebbler → Cragcrab → Forticrab | Stone | Hollowstone Cave |
| 040–042 | Emberhorn → Scorchspine → Calderhorn | Ember | Hollowstone Cave |
| 043–045 | Hummlet → Glimwing → Prismawing | Wind | Fernveil Woods |

| 055–057 | Tidetot → Coralyn → Neptuneer | Tide | Sunthread Marsh |
| 058–060 | Scallet → Ironscale → Aegolin | Stone | Hollowstone Cave |

Every form has embedded sprite art, descriptions, base statistics, learnsets,
level evolutions, capture support, party/storage support, save validation, and
a wild-encounter route. The texture compiler now accepts all 60 numbered PNGs
and uses a portable standard-library RGBA PNG path when Pillow is unavailable.
